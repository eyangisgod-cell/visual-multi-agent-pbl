## 6. 测试执行说明

### 6.1 运行 E2E 测试

```bash
cd apps/web

# 运行冒烟测试
npx playwright test smoke.spec.ts

# 运行多设备测试
npx playwright test multi-device.spec.ts

# 运行所有测试
npx playwright test
```

### 6.2 运行 AI 服务测试

```bash
cd apps/ai-service

# 安装依赖
pip install -r requirements.txt

# 运行集成测试
pytest tests/integration/

# 运行所有测试
pytest tests/
```

### 6.3 需要服务器的测试

以下测试需要启动服务器才能执行：
- 页面可访问性测试
- API 端点测试
- WebSocket 连接测试
- 多设备渲染测试

启动服务器：
```bash
# Web 应用
cd apps/web
npm run dev

# AI Service
cd apps/ai-service
uvicorn app.main:app --reload
```
