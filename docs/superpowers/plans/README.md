## 前置条件

执行任何 Phase 之前，确保：

1. **开发环境**
   - Docker Desktop 已安装
   - Node.js 20+ 已安装
   - Python 3.11+ 已安装
   - Git 已安装

2. **API Keys**
   - LLM API Key（通义千问/文心一言等）
   - （可选）微信开放平台 AppID

3. **代码仓库**
   - 已克隆项目到本地
   - 已创建特性分支

## 快速开始

```bash
# 1. 克隆项目
git clone <repository-url>
cd visual-multi-agent-pbl

# 2. 创建特性分支
git checkout -b feature/mvp-development

# 3. 启动开发环境
cd docker
docker-compose -f docker-compose.dev.yml up -d

# 4. 验证服务
curl http://localhost:3000/api/health  # Next.js
curl http://localhost:8000/api/health  # FastAPI
```
