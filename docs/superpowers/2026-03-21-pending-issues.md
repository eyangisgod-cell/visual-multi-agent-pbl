### TECH-002: PixiJS 移动端性能问题

| 字段 | 内容 |
|------|------|
| **问题描述** | PixiJS 在低端移动设备上可能出现帧率下降、发热、耗电快等问题 |
| **影响等级** | 🟡 中 |
| **影响范围** | 移动端用户体验 |
| **缓解措施** | 1. 设备检测，低端机自动降级（降低帧率、简化渲染）<br>2. 精灵图合并，减少 Draw Call<br>3. 离屏渲染缓存静态元素<br>4. 限制同屏智能体数量 |
| **验收标准** | 中端手机帧率≥24fps，高端手机≥60fps |
| **状态** | 待验证 |

### TECH-003: LLM 响应延迟问题

| 字段 | 内容 |
|------|------|
| **问题描述** | 智能体对话响应慢（3-10 秒），影响用户体验 |
| **影响等级** | 🔴 高 |
| **影响范围** | 核心交互体验 |
| **缓解措施** | 1. **流式输出（SSE）**: 首字延迟<1 秒<br>2. **高频问题缓存**: 常见问题直接返回缓存答案<br>3. **预生成策略**: 任务引导内容预先生成<br>4. **模型路由**: 简单问题用轻量模型，复杂问题用大模型<br>5. **上下文压缩**: 减少 prompt 长度 |
| **验收标准** | 首字延迟<1 秒，完整响应<5 秒（简单问题） |
| **状态** | 设计中 |

### TECH-004: WebSocket 移动端断线问题

| 字段 | 内容 |
|------|------|
| **问题描述** | 移动端网络切换（WiFi↔4G）导致 WebSocket 连接断开 |
| **影响等级** | 🟡 中 |
| **影响范围** | 实时消息推送 |

| **状态** | 设计中 |

### TECH-005: pgvector 大数据量性能问题

| 字段 | 内容 |
|------|------|
| **问题描述** | 向量数据超过 1000 万后，检索性能可能下降 |
| **影响等级** | 🟡 中 |
| **影响范围** | RAG 检索延迟 |
| **缓解措施** | 1. 初期使用 pgvector（<500 万向量性能良好）<br>2. 定期监控检索延迟<br>3. 超过阈值后迁移到 Milvus/Qdrant<br>4. 冷热数据分离（热数据用 Milvus，冷数据存 pgvector） |
| **触发条件** | 向量数>1000 万 或 P99 延迟>200ms |
| **状态** | 监控中 |

## 二、产品设计问题

### PROD-001: 智能体创建门槛设计

| 字段 | 内容 |
|------|------|
| **问题描述** | 智能体创建门槛应该设多高？太低导致质量参差，太高影响活跃度 |
| **影响等级** | 🟡 中 |
| **方案 A** | **低门槛**: 注册即可创建，但公开需要审核<br>优点：激发创造力<br>缺点：劣质内容多 |
| **方案 B** | **等级限制**: 达到 Lv.3 解锁创建，Lv.5 可公开<br>优点：质量相对可控<br>缺点：前期无法体验 |
| **方案 C** | **混合**: 创建无限制，但打上"未认证"标签，用户自行判断<br>优点：平衡自由与质量<br>缺点：标签可能打击积极性 |
| **推荐方案** | 方案 C + AI 辅助创建（降低劣质内容产生） |
| **决策状态** | 待用户确认 |
