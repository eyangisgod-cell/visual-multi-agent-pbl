## 四、失败测试分析

### 4.1 Python AI 服务依赖（~250 个失败）

**影响模块**:
- Agent Memory 系统
- Agent Scope 编排
- RAG 知识检索
- 智能体对话

**解决方案**:
1. 启动 Python AI 服务：`cd ../ai-service && python -m uvicorn main:app --port 8000`
2. 或在测试中模拟 AI 服务响应

### 4.2 CSRF/认证问题（已修复）

**修复内容**:
- 所有测试已更新为使用 `loginAndGetTokens()` 辅助函数
- 正确传递 session、csrf-token、user-role cookies
- 修复 API 响应访问模式（`work.work.status` vs `work.status`）

**验证结果**: 作品审核流程 13 个测试全部通过 ✅

### 4.3 页面超时（~20 个失败）

**原因**: Playwright 等待页面元素超时（5-15 秒）

**解决方案**:
- 增加超时时间
- 优化页面加载性能
- 使用更精确的元素选择器

## 六、测试环境建议

### 6.1 完整测试环境配置

```bash
# 1. 启动数据库和 Redis
docker-compose up -d postgres redis

# 2. 启动 Next.js 开发服务器
cd apps/web && npm run dev

# 3. 启动 Python AI 服务（可选，用于 AI 相关测试）
cd ai-service && python -m uvicorn main:app --port 8000

# 4. 运行 E2E 测试
cd apps/web && npm run test:e2e

# 5. 运行排除 AI 服务的测试
npm run test:e2e -- --grep-invert "agent-memory|agent-scope|rag-"
```

### 6.2 测试前置条件

1. **数据库迁移**: `npm run db:migrate`
2. **种子数据**: 创建测试用户（admin 角色）和测试项目
3. **CSRF Token**: 通过登录流程获取
4. **Session**: 使用 admin 账号登录
