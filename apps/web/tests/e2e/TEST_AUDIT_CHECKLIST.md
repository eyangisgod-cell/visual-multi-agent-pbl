## 4. 断言准确性审核

### 4.1 断言类型使用

| 断言类型 | 使用场景 | 示例 |
|---------|---------|------|
| `toBeVisible()` | 元素可见性 | `await expect(element).toBeVisible()` |
| `toBeHidden()` | 元素隐藏 | `await expect(element).toBeHidden()` |
| `toHaveText()` | 文本内容 | `await expect(element).toHaveText('Success')` |
| `toContainText()` | 包含文本 | `await expect(element).toContainText('Error')` |
| `toHaveAttribute()` | 属性值 | `await expect(link).toHaveAttribute('href', '/home')` |
| `toHaveURL()` | 页面 URL | `await expect(page).toHaveURL('/dashboard')` |
| `toHaveValue()` | 表单值 | `await expect(input).toHaveValue('test')` |
| `toBeEnabled()` | 元素可用 | `await expect(button).toBeEnabled()` |
| `toBeDisabled()` | 元素禁用 | `await expect(button).toBeDisabled()` |

### 4.2 超时处理

- [ ] 所有异步操作都有合理的超时时间
- [ ] 使用 `waitForURL()` 等待导航完成
- [ ] 使用 `waitForFunction()` 等待复杂条件
