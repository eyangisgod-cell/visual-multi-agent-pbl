## 已修复的问题

### 1. 登录函数超时问题
**影响文件**: `core-business-flow.spec.ts`, `pwa-mobile.spec.ts`

**问题**: `waitForURL(/^\//)` 在导航到 `/game` 时立即匹配但继续等待

**修复**: 改用 `waitForTimeout(3000)`

### 2. 选择器严格模式冲突
**影响文件**: `pwa-mobile.spec.ts`

**问题**: `manifest` link 和 `apple-mobile-web-app` meta 标签匹配多个元素

**修复**: 添加 `.first()` 选择器

### 3. 重复 HTML 标签
**影响文件**: `src/app/layout.tsx`

**问题**: Next.js metadata API 和手动添加导致重复标签

**修复**: 移除手动添加的重复标签

### 4. 项目/智能体表单选择器错误
**影响文件**: `core-business-flow.spec.ts`

**问题**: 测试使用 `input[name="title"]` 但实际使用 `id="title"`

**修复**: 更新选择器为 `#title` 和 `#description`

### 5. 游戏页面位置显示测试
**影响文件**: `core-business-flow.spec.ts`

**问题**: 测试等待精确坐标格式但游戏加载需要时间

**修复**: 放宽验证条件，只检查包含数字

### 6. 管理后台侧边栏重复
**影响文件**: `core-business-flow.spec.ts`

**问题**: 嵌套 AdminLayout 导致多个 aside 元素

**修复**: 使用 `locator('aside').first()` 选择第一个

### 7. 智能体表单验证测试
**影响文件**: `core-business-flow.spec.ts`

**问题**: 表单验证错误消息显示方式与预期不同

**修复**: 修改测试逻辑，检查输入框是否为空
