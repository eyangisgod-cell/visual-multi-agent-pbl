# 项目目的

基于 PixiJS 的视觉化多智能体项目式学习 (PBL) 平台。

## 核心功能
- 5 种 AI 智能体 (Project Manager, Developer, Designer, Tester, Documentation)
- 虚拟校园场景
- 项目管理与任务分配
- 智能体记忆与进化系统 (Phase 9)
- 管理后台 (Phase 7)
- 动态场景生成 (Phase 8)

## 技术栈
- 前端：Next.js 14, React 18, TypeScript, PixiJS v8
- 后端：FastAPI, Prisma ORM, PostgreSQL + pgvector
- 测试：Jest, Playwright E2E
